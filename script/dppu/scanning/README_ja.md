# 分類とscan

[English](README.md)

`classify_configuration`を`run_scan`とviewerで共有し、二変数と固定形状の半径分類を返します。有限最小・未達成下限・退化・非有界を別々に記録します。TT/REEは分類適用外で、曲線は各engineから取得します。

[曲率モデルと保存キー](../../docs/WEYL_MODELS_ja.md)。選択作用はquadratic_scalarを使い、既定はEC_IRR。従来のweyl_scalarキーはLC基準を保持する。
