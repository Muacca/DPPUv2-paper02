# 曲率とWeyl射影

[English](README.md)

`compute_riemann_tensor`は非座標基底の構造定数項を含み、`verify_antisymmetry_strict`は両添字対を検査します。Ricci縮約とLC-Weylは別の関数です。形式Hodge・Pontryaginの規格化は計算規約第11節、3幾何の空間block構造と零のPontryaginは公開の記号計算補足で確認できます。
