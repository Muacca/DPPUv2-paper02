# symbolic・epsilonの補助

[English](README.md)

`epsilon_symbol`、`levi_civita_4d`、`levi_civita_nd`は反対称symbolを返す。`prove_zero`は厳密なsymbolic簡約を試みBooleanと手法名を返すが、timeout_seconds引数は現在使われていない。`find_nonzero_witness`と`generate_test_points`は有限数値検査であり、反例が見つからないことは恒等式の証明ではない。engine振幅を用いる軸性入力配列はτで、幾何学的捩率は−τである。
