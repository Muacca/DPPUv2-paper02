# Spatial geometry

[日本語](README_ja.md)

`S3S1Engine`, `T3S1Engine`, and `Nil3S1Engine` share the BaseFrameEngine API. They implement setup and metric/frame steps. Circle circumference is L. Spherical physical radius is r/2. Torus periods are 2pi and Nil periods (2pi,2pi,4pi^2). Shape preserves volume.
