# Input tau and NY

[日本語](README_ja.md)

`construct_torsion_tensor` returns the code array tau. `Mode` selects AX/VT/MX. `NyVariant` selects FULL=TT-REE or separate positive-TT/positive-REE diagnostic actions. TT uses 1/4 and REE uses 1/2. Geometric torsion is -tau; FULL is zero on the specified family.
