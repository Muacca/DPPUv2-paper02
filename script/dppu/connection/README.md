# Connections and indices

[日本語](README_ja.md)

`compute_christoffel_frame(C, dim)` solves the LC convention; `check_torsion_free` reconstructs C[a,b,c]+Gamma[a,c,b]-Gamma[a,b,c]. `compute_contortion` accepts the legacy tau array, using the positive half cyclic combination. The last connection index is the derivative direction.
