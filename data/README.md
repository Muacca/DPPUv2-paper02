# Figure and table data / 図表データ

[English data guide](revised/README.md) / [日本語データ案内](revised/README_ja.md)

`revised/` contains the six CSV datasets and parameters used for the current figures and representative table. The comparison in Appendix D is part of this dataset. The supplied files correspond to the equations and parameter choices stated in the paper.
